# Synthetic autoimmune demo

Package ID: `synthetic-autoimmune-demo`.

Source: `synthetic_autoimmune_demo/` in COHORTome, generated by
`scripts/generate_synthetic_autoimmune_demo.py` with its checked-in reference
sidecars. It contains 90 fictional RA, SLE and control participants, linked to
transcriptomics, methylation, immune-cell and serology measurements.

Purpose: a small multimodal example usable offline and as a downloadable
reference package. Values are independently simulated, not real study records
or evidence of clinical effects.

Status: version 0.1.1-preview is packaged, schema-validated and uploaded as a
private GitHub prerelease. It includes shortened COH-AUTO ClarIDs.
Resource versions and checksums identify the package independently of app commits.
Review reference annotations and other asset terms before public distribution.
