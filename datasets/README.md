# Dataset recipes

One directory per dataset package. These directories hold source references,
preparation recipes, package documentation and review information. Large inputs
and generated archives do not belong here.

For each package, document:

- Origin: synthetic generator or public source accession, with citations.
- Exact source release/checksums and redistribution terms.
- Preparation steps, tool versions and measurement units/transforms.
- Patient, sample and visit linkage; omissions and known limitations.
- Compatible COHORTome schema/validator version and validation outcome.
- Supported example analyses and the limits of those examples.
- Published package version, archive checksum and DOI when available.

Use the existing synthetic sources as reference inputs, not as an exemption
from validation. Each source has one authoritative location; archives are
reproducible release artifacts, not independently edited datasets.
